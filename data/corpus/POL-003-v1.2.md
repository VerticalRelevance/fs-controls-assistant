Source ID: POL-003
Title: Encryption Standard
Version: 1.2
Effective date: 2025-09-01
Status: current

All customer data stores must be encrypted at rest using AES-256 with keys managed in AWS KMS.
Data in transit must use TLS 1.2 or higher.
Customer managed KMS keys must have automatic rotation enabled (yearly).
Related control: CTL-002.
